# Dialog 对话框

`Dialog` 用于内容提示和交互对话框，适合展示重要信息或要求用户确认。

## 基础配置

```yaml
!Dialog
layout:
- !Grid {}
```

## 主要特性

- 突出显示：在界面层级中位于最前。
- 标准结构：通常包含标题、内容和操作按钮。

## 使用场景

- 删除、退出等操作确认
- 重要信息提示
- 用户输入收集
- 系统通知
