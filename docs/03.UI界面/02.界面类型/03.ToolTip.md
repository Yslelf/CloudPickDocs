# ToolTip 工具提示

`ToolTip` 用于显示物品提示和组件提示等浮动信息。

## 基础配置

```yaml
!ToolTip
tipXOffset: 10 # 设置提示框的 X 轴偏移量
tipYOffset: 10 # 设置提示框的 Y 轴偏移量
layout:
- !Grid {}
```

## 特性说明

- 自动定位：根据鼠标位置自动调整显示位置。
- 偏移控制：通过 `tipXOffset` 和 `tipYOffset` 微调显示位置。
- 悬停触发：通常在鼠标悬停时显示。

## 使用场景

- 物品属性说明
- 按钮功能提示
- 图标含义解释
