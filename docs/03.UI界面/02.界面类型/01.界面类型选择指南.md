# 界面类型选择指南

界面类型是 UI 的根载体与容器。根据具体需求选择合适的类型，可以让界面结构更清晰。

| 界面类型 | 适用场景 | 特点 | 用户交互 |
| --- | --- | --- | --- |
| [Segment](./02.Segment.md) | 主界面、HUD、游戏 UI | 持久显示，功能完整 | 主要操作界面 |
| [ToolTip](./03.ToolTip.md) | 提示信息、说明文字 | 临时浮动，信息展示 | 悬停查看 |
| [Component](./04.Component.md) | 可复用 UI 元素、聊天组件 | 模块化，嵌入使用 | 集成在其他界面中 |
| [Popup](./05.Popup.md) | 临时操作、快捷设置 | 弹出显示，轻量级 | 快速操作后关闭 |
| [Dialog](./06.Dialog.md) | 重要确认、用户输入 | 模态显示，需要响应 | 必须交互后关闭 |
| [ContextMenu](./07.ContextMenu.md) | 右键菜单、快捷操作 | 上下文相关，精确定位 | 右键触发 |
