# 选择布局容器

不同容器适合不同的排列方式。优先选择能够直接表达界面结构的容器，不要为了简单排列使用复杂的嵌套。

## 快速选择

1. 需要行和列，或者需要让控件相互覆盖：使用 `Grid`。
2. 需要把控件排成一行或一列：使用 `StackPanel`。
3. 空间不足时需要自动换行：使用 `WrapPanel`。
4. 需要固定坐标：使用 `Canvas`。
5. 内容可能超出显示区域：使用 `ScrollView` 包裹内容。
6. 只需要背景、边框或圆角：使用 `Border` 包裹一个子控件。

| 容器 | 排列方式 | 常见用途 |
| --- | --- | --- |
| `Grid` | 行列布局或重叠布局 | 表单、面板、复杂界面、背景与前景叠放 |
| `StackPanel` | 水平或垂直顺序排列 | 菜单、工具栏、简单列表 |
| `WrapPanel` | 顺序排列并自动换行 | 图标集合、标签、物品列表 |
| `Canvas` | 绝对坐标 | 绘图区域、固定坐标元素 |
| `ScrollView` | 单个可滚动内容 | 长列表、超出窗口的设置页面 |
| `Border` | 包裹一个子控件 | 背景、边框、圆角和内容分组 |

## Grid

`Grid` 是最通用的布局容器。行高和列宽可以使用固定数值、比例值或 `Auto`。

```yaml
layout:
- !Grid
  rows:
  - height: Auto
  - height: 1*
  columns:
  - width: 100
  - width: 1*
  children:
  - !TextBlock
    text: 标题
    row: 0
    column: 0
    columnSpan: 2
  - !TextBlock
    text: 左侧内容
    row: 1
    column: 0
  - !TextBlock
    text: 主体内容
    row: 1
    column: 1
```

适合：结构明确、需要固定区域与可伸缩区域组合的界面。

不必使用：只是把少量控件排成一行或一列时，`StackPanel` 更直接。

## StackPanel

`StackPanel` 按声明顺序排列子控件。`orientation` 为 `Vertical` 时纵向排列，为 `Horizontal` 时横向排列。

```yaml
layout:
- !StackPanel
  orientation: Vertical
  children:
  - !TextBlock
    text: 用户名
  - !TextBox
    width: 180
  - !Button
    text: 登录
    horizontalAlign: Right
```

适合：短列表、菜单、工具栏和简单表单。

内容很多时，可以把它放进 `ScrollView`。不要直接在不可滚动区域内堆放大量控件。

## WrapPanel

`WrapPanel` 会顺序排列子控件，并在剩余空间不足时换行。

```yaml
layout:
- !WrapPanel
  orientation: Horizontal
  children:
  - !Button
    text: 选项一
    width: 80
  - !Button
    text: 选项二
    width: 80
  - !Button
    text: 选项三
    width: 80
```

适合：数量不固定的按钮、图标或标签集合。

如果必须保持严格的行列对齐，应改用 `Grid`。

## Canvas

`Canvas` 使用坐标定位子控件。

```yaml
layout:
- !Canvas
  children:
  - !Image
    source: texture://icon.png
    width: 32
    height: 32
    Canvas.Left: 40
    Canvas.Top: 20
```

适合：绘图、拖拽或确实依赖固定坐标的界面。

普通界面应尽量避免使用 `Canvas`，因为固定坐标不容易适配不同尺寸。

## ScrollView

`ScrollView` 只能包含一个直接子控件。如果需要滚动多个控件，先用布局容器把它们组合起来。

```yaml
layout:
- !ScrollView
  verticalBarVisibility: Auto
  child:
  - !StackPanel
    orientation: Vertical
    children:
    - !TextBlock
      text: 第一项
    - !TextBlock
      text: 第二项
    - !TextBlock
      text: 第三项
```

## Border

`Border` 负责背景和边框装饰，也只能包含一个直接子控件。

```yaml
layout:
- !Border
  borderThickness: 2
  borderBrush: White
  cornerRadius: 4
  padding: "8, 8, 8, 8"
  child:
  - !TextBlock
    text: 面板内容
```

## 容器嵌套

复杂界面可以组合多个容器，但每一层都应承担明确职责。例如，外层 `Grid` 划分主体区域，内部 `StackPanel` 排列一组按钮，最外面再用 `Border` 提供背景。

嵌套层数过多会增加布局计算，也会让配置难以维护。能够用一层 `Grid` 表达的结构，就不必拆成多层容器。
