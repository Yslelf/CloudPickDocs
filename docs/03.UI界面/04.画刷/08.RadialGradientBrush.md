# RadialGradientBrush

`RadialGradientBrush` 以指定点为中心，沿半径方向进行圆形渐变。

| 属性 | 说明 |
| --- | --- |
| `center` | 圆心坐标。 |
| `radius` | 渐变半径。 |
| `gradientStops` | 色标列表。 |

```yaml
background: !RadialGradientBrush
  center: 0.5,0.5
  radius: 0.8
  gradientStops:
  - color: 0xFFFF0000
    offset: 0.0
  - color: 0x00000000
    offset: 1.0
```
