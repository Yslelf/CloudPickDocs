# ImageBrush

`ImageBrush` 加载静态图片作为控件的背景或填充。

| 属性 | 说明 |
| --- | --- |
| `source` | 图片路径，格式如 `texture://文件名.png`。 |
| `alpha` | 透明度。 |

```yaml
background: !ImageBrush
  source: texture://ui/button.png
  alpha: 200
```
