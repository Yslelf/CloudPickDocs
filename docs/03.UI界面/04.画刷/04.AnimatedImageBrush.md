# AnimatedImageBrush

`AnimatedImageBrush` 用于显示 GIF、APNG 等动态图片。

| 属性 | 说明 |
| --- | --- |
| `source` | 动态图片路径。 |
| `oneShot` | 是否只播放一次，取值为 `true` 或 `false`。 |

```yaml
background: !AnimatedImageBrush
  source: texture://animations/fire.gif
  oneShot: true
```
