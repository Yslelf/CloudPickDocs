# AngularGradientBrush

`AngularGradientBrush` 以指定点为中心，沿角度方向进行颜色过渡。

| 属性 | 说明 |
| --- | --- |
| `center` | 渐变中心点。 |
| `angle` | 渐变起始角度，单位为度。 |
| `gradientStops` | 色标列表。 |

```yaml
background: !AngularGradientBrush
  center: 0.5,0.5
  angle: 45
  gradientStops:
  - color: 0xFFFF0000
    offset: 0.0
  - color: 0xFFFFFF00
    offset: 1.0
```
