# 画刷

画刷（Brush）用于定义 UI 控件的背景、边框和填充等区域的显示效果。它可以呈现纯色、图片、渐变、动画和状态切换等视觉效果。

## 公有属性

所有画刷类型都支持以下属性。

| 属性名 | 类型或取值 | 说明 |
| --- | --- | --- |
| `bounds` | `x,y,width,height` | 显示范围，依次为左、上、宽、高，单位为像素。 |
| `alpha` | `0`～`255` | 透明度；`0` 为完全透明，`255` 为完全不透明。 |

## 基本写法

画刷常用于控件的 `background`、`borderBrush` 等属性。

```yaml
# 简化写法
background: 0xFFFF0000

# 展开写法
background: !ColorBrush
  color: 0xFFFF0000
  alpha: 200

# 嵌套写法
background: !ScaleBrush
  brush: !ImageBrush
    source: texture://icon.png
    alpha: 255
  scaleWidth: 20
  scaleHeight: 20
```

简化写法适合纯色、静态图片或动态图片等快速配置；展开写法可设置画刷的详细属性；嵌套写法可组合多个画刷的能力。

## 选择建议

| 需求 | 推荐画刷 |
| --- | --- |
| 纯色背景或简单色块 | `ColorBrush` |
| 图片背景或纹理填充 | `ImageBrush` |
| GIF 或 APNG 动画 | `AnimatedImageBrush` |
| 可拉伸的按钮或面板 | `NinePatchBrush` |
| 平滑颜色过渡 | 渐变画刷 |
| 根据交互状态切换样式 | `StateBrush` 或 `ColorStateBrush` |
