# ColorStateBrush

`ColorStateBrush` 根据控件状态切换颜色。

`brushs` 是颜色列表，每项包含状态数组 `states` 和对应颜色 `color`。

```yaml
background: !ColorStateBrush
  brushs:
  - states: [Pressed]
    color: 0xFFAA0000
  - states: [Hovered]
    color: 0xFFFF6600
  - states: [Normal]
    color: 0xFF336699
```
