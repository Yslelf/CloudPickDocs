# NinePatchBrush

`NinePatchBrush` 通过指定图片的不拉伸边界，让按钮、面板等 UI 元素自适应尺寸，同时避免边角变形。

| 属性 | 说明 |
| --- | --- |
| `source` | 图片路径。 |
| `border` | 四周不拉伸区域的宽度，格式为 `左,上,右,下`，单位为像素。 |

```yaml
background: !NinePatchBrush
  source: texture://ui/panel.9.png
  border: 2,4,2,4
```
