# StateBrush

`StateBrush` 根据控件状态切换不同的画刷，适合实现悬停、按下和禁用等交互反馈。

`brushs` 是画刷列表，每项包含状态数组 `states` 和对应画刷 `brush`。

```yaml
background: !StateBrush
  brushs:
  - states: [Pressed]
    brush: texture://btn_pressed.png
  - states: [Hovered]
    brush: texture://btn_hover.png
  - states: [Normal]
    brush: texture://btn_normal.png
```
