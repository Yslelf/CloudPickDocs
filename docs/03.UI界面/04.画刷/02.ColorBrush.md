# ColorBrush

`ColorBrush` 是纯色画刷，适合按钮底色、面板背景和简单色块。

| 属性 | 类型或取值 | 说明 |
| --- | --- | --- |
| `color` | ARGB 或 RGB | 画刷颜色。 |
| `alpha` | `0`～`255` | 透明度，默认值为 `255`。 |

```yaml
background: !ColorBrush
  color: 0xFF3498DB
  alpha: 255
```
