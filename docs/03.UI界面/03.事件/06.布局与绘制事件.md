# 布局与绘制事件

布局与绘制事件用于响应控件尺寸、位置变化以及绘制前的处理时机。

| 事件 | 触发时机 | 常见用途 |
| --- | --- | --- |
| `layoutChange` | 控件的布局结果发生变化时 | 响应尺寸或位置改变 |
| `preDraw` | 控件即将绘制前 | 在绘制前同步轻量状态 |

## 布局变化示例

```yaml
- !Grid
  name: content
  events:
    layoutChange: |-
      Chat.send('布局发生变化');
  children:
  - !TextBlock
    text: 内容
```

::: warning 性能提示
布局与绘制事件可能频繁触发。不要在回调中反复修改会再次引发布局的属性，否则可能形成连续重排。
:::
