# 生命周期与周期事件

生命周期事件适用于 `Segment` 等界面根对象，也可用于普通控件的初始化与清理。周期事件用于持续更新界面状态。

| 事件 | 触发时机 | 常见用途 |
| --- | --- | --- |
| `attached` | 对象被添加到界面并进入使用状态时 | 初始化文本、缓存数据、启动逻辑 |
| `detached` | 对象从界面移除时 | 清理临时数据、停止持续任务 |
| `tick` | 界面运行期间每帧触发 | 状态刷新、计时和轻量动画逻辑 |

## Segment 生命周期示例

```yaml
!Segment
name: main
events:
  attached: |-
    Chat.send('界面已打开');
    self.data = { ticks: 0 };
  tick: |-
    self.data.ticks++;
  detached: |-
    Chat.send('界面已关闭');
    self.data = null;
layout:
- !Grid {}
```

## 控件生命周期示例

```yaml
- !TextBlock
  text: ''
  events:
    attached: |-
      self.text = '控件已加载';
    detached: |-
      self.data = null;
```

::: warning 性能提示
`tick` 会高频执行。只做必要的判断和赋值，避免网络请求、复杂循环和大量对象创建。
:::
