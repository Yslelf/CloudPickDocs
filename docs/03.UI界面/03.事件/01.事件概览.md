# 事件概览

事件会在界面或控件进入特定状态时执行 JavaScript，让静态 UI 响应生命周期、用户输入和布局变化。

## 基本写法

事件写在对象的 `events` 字段中。一个对象可以同时绑定多个事件。

```yaml
- !Button
  text: 点击我
  events:
    attached: |-
      self.text = '已加载';
    click: |-
      Chat.send('按钮被点击了');
      self.text = '已点击';
```

`self` 表示当前触发事件的界面或控件对象，可以读取和修改它的属性。

## 事件分类

| 分类 | 主要事件 | 用途 |
| --- | --- | --- |
| [生命周期与周期事件](./02.生命周期与周期事件.md) | `attached`、`detached`、`tick` | 初始化、清理和持续更新 |
| [鼠标输入事件](./03.鼠标输入事件.md) | `click`、`mouseEnter`、`mouseWheel` 等 | 鼠标点击、移动和滚轮输入 |
| [键盘与焦点事件](./04.键盘与焦点事件.md) | `key`、`focusChange` | 键盘操作和输入焦点变化 |
| [触摸输入事件](./05.触摸输入事件.md) | `touchDown`、`touchMove` 等 | 触摸屏和多指输入 |
| [布局与绘制事件](./06.布局与绘制事件.md) | `layoutChange`、`preDraw` | 响应尺寸、位置和绘制时机 |
| [上下文菜单事件](./07.上下文菜单事件.md) | `contextClick`、`createContextMenu` | 右键操作与菜单创建 |

## 使用建议

- `tick` 每帧触发，不要在其中执行复杂计算或频繁创建对象。
- 在 `attached` 中初始化，在 `detached` 中释放不再需要的数据。
- 并非每种事件在每种设备或控件上都有实际触发条件，应按使用场景选择。
- 可使用 `Chat.send('调试信息')` 检查事件是否触发。
