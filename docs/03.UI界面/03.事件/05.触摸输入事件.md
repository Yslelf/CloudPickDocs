# 触摸输入事件

触摸事件用于支持触摸屏输入的运行环境。桌面鼠标环境通常不会触发这些事件。

| 事件 | 触发时机 |
| --- | --- |
| `touchDown` | 手指按下时 |
| `touchUp` | 手指抬起时 |
| `touchMove` | 手指在屏幕上移动时 |
| `touchCancel` | 当前触摸操作被系统取消时 |
| `touchPointerDown` | 多指触控中的触点按下时 |
| `touchPointerUp` | 多指触控中的触点抬起时 |

## 基础示例

```yaml
- !Button
  text: 触摸区域
  events:
    touchDown: |-
      self.text = '按下';
    touchUp: |-
      self.text = '松开';
    touchCancel: |-
      self.text = '已取消';
```

设计触摸界面时应增大可点击区域，并为取消事件准备恢复逻辑。
