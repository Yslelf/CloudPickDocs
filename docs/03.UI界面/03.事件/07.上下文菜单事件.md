# 上下文菜单事件

上下文菜单事件用于响应右键或特殊上下文操作，并在需要时创建菜单内容。

| 事件 | 触发时机 | 常见用途 |
| --- | --- | --- |
| `contextClick` | 控件发生上下文点击时 | 执行右键快捷操作 |
| `createContextMenu` | 即将创建上下文菜单时 | 根据当前状态准备菜单 |

## 事件示例

```yaml
- !Button
  text: 右键操作
  contextMenu: context_menu.yml
  events:
    contextClick: |-
      Chat.send('触发了上下文点击');
    createContextMenu: |-
      Chat.send('正在创建上下文菜单');
```

菜单文件的结构请参阅[ContextMenu 上下文菜单](../02.界面类型/07.ContextMenu.md)。
