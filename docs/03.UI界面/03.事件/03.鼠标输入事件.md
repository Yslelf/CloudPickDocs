# 鼠标输入事件

鼠标事件用于按钮、文本、图片和其他可交互控件。

## 点击与按键

| 事件 | 触发时机 |
| --- | --- |
| `click` | 鼠标任意键点击控件时 |
| `longClick` | 鼠标长按控件时 |
| `mouseRelease` | 鼠标按键释放时 |
| `mouseLeftDown` / `mouseLeftUp` | 鼠标左键按下 / 松开时 |
| `mouseRightDown` / `mouseRightUp` | 鼠标右键按下 / 松开时 |
| `mouseMiddleDown` / `mouseMiddleUp` | 鼠标中键按下 / 松开时 |

## 移入、移动与滚轮

| 事件 | 触发时机 |
| --- | --- |
| `mouseEnter` | 指针进入控件区域时 |
| `mouseMove` | 指针在控件区域内移动时 |
| `mouseLeave` | 指针离开控件区域时 |
| `mouseWheel` | 指针位于控件区域内并滚动滚轮时 |
| `scroll` | 滚动输入时；部分版本或控件可能不触发 |

## 悬停与点击示例

```yaml
- !Button
  text: 悬停按钮
  background: 0xFF0000FF
  events:
    mouseEnter: |-
      self.background = 0xFFFF0000;
    mouseLeave: |-
      self.background = 0xFF0000FF;
    click: |-
      Chat.send('按钮被点击了');
```
