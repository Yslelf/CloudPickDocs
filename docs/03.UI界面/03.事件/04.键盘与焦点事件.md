# 键盘与焦点事件

键盘输入通常由当前拥有焦点的控件接收。文本框、快捷键区域和需要键盘操作的界面应同时考虑焦点状态。

| 事件 | 触发时机 | 常见用途 |
| --- | --- | --- |
| `key` | 控件区域内按下键盘按键时 | 快捷键、确认、取消和方向操作 |
| `focusChange` | 控件获得或失去焦点时 | 高亮输入框、验证内容和切换提示 |

## 键盘事件示例

```yaml
- !TextBox
  name: search
  events:
    key: |-
      if (event.keyCode === RETURN) {
        Chat.send('按下了回车键');
      }
```

## 焦点事件示例

```yaml
- !TextBox
  name: playerName
  events:
    focusChange: |-
      Chat.send('输入焦点发生变化');
```

事件参数的可用字段可能随事件和版本不同。使用前可先输出关键信息进行调试。
