# 布局系统

布局系统负责计算控件的大小和位置。一次完整的布局通常分为两个阶段：先测量控件需要的空间，再把控件排列到父容器分配的区域中。

## 布局容器

布局容器用于组织多个子控件。选择合适的容器，可以减少手动计算坐标的工作，也能让界面更容易适配不同窗口大小。

| 容器 | 说明 |
| --- | --- |
| `Canvas` | 使用坐标明确指定子控件的位置，适合自由布局或需要绝对定位的场景。 |
| `Grid` | 使用行和列划分空间；未指定行列时，子控件可以相互覆盖。 |
| `StackPanel` | 按水平或垂直方向，把子控件排列成一行或一列。 |
| `WrapPanel` | 顺序排列子控件；当前行或列空间不足时，自动换到下一行或下一列。 |

如果需要让多个控件占用同一个区域并允许它们重叠，可使用未划分行列的 `Grid`。需要精确划分行列时也使用 `Grid`；只需要连续排列时，优先使用 `StackPanel` 或 `WrapPanel`。

## 控件边界

参与布局的每个控件都可以看成一个矩形。这个矩形的位置和大小由以下因素共同决定：

- 父容器提供的可用空间；
- 控件的 `width`、`height`、`minWidth` 和 `minHeight`；
- 控件的 `margin` 和 `padding`；
- 水平、垂直对齐方式；
- 父容器自身的布局规则。

父控件的尺寸和约束也会影响子控件。例如，父容器变窄后，使用自动换行的 `WrapPanel` 可能会重新排列全部子控件。

## 布局过程

布局是一个从父控件到子控件递归执行的过程。大致流程如下：

1. 读取控件是否可见等基础状态。
2. 计算 `width`、`height`、`margin` 等尺寸属性。
3. 应用父容器的布局规则，例如停靠方向或排列方向。
4. 在所有子控件完成测量后，为它们分配最终区域。
5. 按计算结果绘制界面。
6. 当子控件、尺寸或布局属性发生变化时，重新执行必要的布局。

子控件越多、嵌套越深，布局计算量通常越大。`Canvas` 的规则比较简单，而包含大量行列和嵌套关系的 `Grid` 需要更多计算。

## 测量与排列

### 测量阶段

测量阶段用于确定控件希望占用的空间。

父容器首先向子控件提供可用尺寸。子控件结合自身内容、固定尺寸、最小尺寸、外边距等信息，计算所需大小。这个结果只是期望尺寸，并不一定等于最终显示尺寸。

不可见且不参与布局的控件会被跳过，其期望尺寸按零处理。

### 排列阶段

排列阶段用于确定控件最终占用的矩形区域。

父容器根据自身规则和子控件的期望尺寸，为每个子控件分配位置和大小。随后再应用外边距、对齐方式等属性，得到最终布局结果。

子控件不一定会填满父容器分配的全部空间。例如，设置固定宽度并居中对齐后，控件只会占用指定宽度，其余空间保留在两侧。

## 常用布局属性

| 属性 | 作用 |
| --- | --- |
| `width`、`height` | 设置固定宽度和高度。 |
| `minWidth`、`minHeight` | 限制控件能够缩小到的最小尺寸。 |
| `margin` | 设置控件与周围控件或父容器边缘的距离。 |
| `padding` | 设置控件边缘与自身内容之间的距离。 |
| `horizontalAlign` | 设置水平对齐方式：`Left`、`Center`、`Right` 或 `Stretch`。 |
| `verticalAlign` | 设置垂直对齐方式：`Top`、`Center`、`Bottom` 或 `Stretch`。 |
| `visibility` | 控制控件是否显示以及是否继续占用布局空间。 |

完整属性说明请参阅[公共属性](./07.公共属性.md)。

## 示例

下面使用 `Grid` 作为根容器，并把标题和按钮垂直排列：

```yaml
layout:
- !Grid
  name: 主面板
  width: 320
  height: 180
  horizontalAlign: Center
  verticalAlign: Center
  children:
  - !StackPanel
    name: 内容区域
    verticalAlign: Center
    children:
    - !TextBlock
      name: 标题
      text: 布局示例
      horizontalAlign: Center
      marginBottom: 12
    - !Button
      name: 确认按钮
      width: 120
      height: 36
      horizontalAlign: Center
```

需要让控件按绝对坐标放置时，可以使用 `Canvas`：

```yaml
layout:
- !Canvas
  name: 自由布局区域
  children:
  - !Button
    name: 左上角按钮
    width: 100
    height: 32
    Canvas.Left: 20
    Canvas.Top: 20
```

## 使用建议

1. 优先使用相对布局、对齐和边距，让界面能够适配不同尺寸。
2. 只有确实需要固定坐标时才使用 `Canvas` 和 `absX`、`absY`。
3. 避免不必要的多层容器嵌套，以减少布局计算。
4. 频繁修改尺寸或位置会触发布局更新；动画场景中应尽量减少无关控件的重新布局。
5. 隐藏控件时，先确认它是否还需要保留原来的布局空间。
