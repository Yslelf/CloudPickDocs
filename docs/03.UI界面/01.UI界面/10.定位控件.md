# 定位控件

选好布局容器后，可以通过水平对齐、垂直对齐、外边距和内边距进一步控制控件的位置。

## 水平对齐

`horizontalAlign` 决定控件如何使用父容器分配给它的水平空间。

| 值 | 效果 |
| --- | --- |
| `Left` | 靠左放置。 |
| `Center` | 水平居中。 |
| `Right` | 靠右放置。 |
| `Stretch` | 拉伸并占满可用宽度。 |

```yaml
layout:
- !Grid
  children:
  - !Button
    text: 居中按钮
    width: 120
    horizontalAlign: Center
```

控件设置固定 `width` 后，`Left`、`Center` 和 `Right` 的效果最明显。使用 `Stretch` 时不要同时依赖固定宽度填满空间。

## 垂直对齐

`verticalAlign` 决定控件如何使用父容器分配给它的垂直空间。

| 值 | 效果 |
| --- | --- |
| `Top` | 靠顶部放置。 |
| `Center` | 垂直居中。 |
| `Bottom` | 靠底部放置。 |
| `Stretch` | 拉伸并占满可用高度。 |

```yaml
layout:
- !Grid
  children:
  - !TextBlock
    text: 右下角文本
    horizontalAlign: Right
    verticalAlign: Bottom
```

## 外边距

`margin` 表示控件边缘与周围区域之间的距离。四个值的顺序以项目现有格式为准：上、右、下、左。

```yaml
layout:
- !Grid
  children:
  - !Button
    text: 确认
    horizontalAlign: Right
    verticalAlign: Bottom
    margin: "10, 20, 10, 20"
```

也可以分别设置四个方向：

```yaml
marginLeft: 20
marginTop: 10
marginRight: 20
marginBottom: 10
```

边距会占用布局空间。父容器空间不足时，过大的边距可能挤压控件内容。

## 内边距

`padding` 表示控件边缘与自身内容之间的距离。它常用于按钮、边框和其他内容控件。

```yaml
layout:
- !Border
  background: 0x80000000
  padding: "8, 12, 8, 12"
  child:
  - !TextBlock
    text: 带内边距的内容
```

`margin` 影响控件外部，`padding` 影响控件内部。两者可以同时使用。

## 对齐与边距组合

下面把面板放在父容器右下角，并与右侧、底部各保留一定距离：

```yaml
layout:
- !Grid
  children:
  - !Border
    width: 220
    height: 100
    horizontalAlign: Right
    verticalAlign: Bottom
    marginRight: 16
    marginBottom: 16
    padding: "8, 8, 8, 8"
    background: 0x80000000
    child:
    - !TextBlock
      text: 状态信息
```

## Canvas 绝对定位

在 `Canvas` 中，可以通过 `Canvas.Left` 和 `Canvas.Top` 指定子控件相对画布左上角的位置。

```yaml
layout:
- !Canvas
  children:
  - !Button
    text: 固定位置
    width: 100
    height: 32
    Canvas.Left: 50
    Canvas.Top: 30
```

绝对定位不会自动适配父容器尺寸。除绘图、拖拽等特殊场景外，优先使用对齐和边距。

## 可见性对布局的影响

| 值 | 是否显示 | 是否占用布局空间 |
| --- | --- | --- |
| `Visible` | 是 | 是 |
| `Hidden` | 否 | 是 |
| `Collapsed` | 否 | 否 |

如果只是暂时隐藏控件但希望周围布局保持不变，使用 `Hidden`；如果希望其他控件补上它的位置，使用 `Collapsed`。
